# Contributing to Smart Library

First off, thank you for considering contributing to the Smart Library Recommendation System!

## Where do I go from here?

If you've noticed a bug or have a feature request, make one! It's generally best if you get confirmation of your bug or approval for your feature request this way before starting to code.

## Fork & create a branch

If this is something you think you can fix, then fork Smart Library and create a branch with a descriptive name.

## Get the test suite running

Make sure all tests pass before making any changes. 
Run the frontend build with `npm run build` and ensure the backend builds with `mvn clean compile`.

## Implement your fix or feature

At this point, you're ready to make your changes! Feel free to ask for help; everyone is a beginner at first.

## Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with Smart Library's master branch.
Then, push your feature branch and make a Pull Request.
